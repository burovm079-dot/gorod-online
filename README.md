# ГОРОД ONLINE — Воронеж

Мобильная веб-платформа с интерактивной картой Воронежа и городскими сервисами.

## Сейчас реализовано
- Карта OpenStreetMap с ограничением области просмотра Воронежем.
- Поиск улиц и мест в пределах города через Nominatim.
- Текущая погода и прогноз на 3 дня из Open-Meteo; текущие данные обновляются каждые 15 минут.
- Остановки и линии автобусных/троллейбусных/трамвайных маршрутов из OpenStreetMap, отображаемые при среднем приближении.
- Ссылка на официальный сервис оператора общественного транспорта: https://eogpp-vrn.ru/
- Честные статусы: движущиеся GPS-позиции транспорта и пробки не имитируются: для них пока нет подтверждённого открытого источника данных.

## Публикация через GitHub Pages
1. Открой Settings репозитория.
2. Перейди в Pages.
3. В разделе Build and deployment выбери Deploy from a branch.
4. Выбери ветку main и папку /(root), затем Save.
5. После публикации сайт будет доступен по адресу https://burovm079-dot.github.io/gorod-online/

## Источники
